SECTION 05

RACE CONDITION PREVENTION

Demonstrates why synchronization is required when multiple threads access shared resources simultaneously, and how threading.Lock() (Mutex) guarantees mutual exclusion to prevent data corruption.

The Shared Resource Problem

Suppose Shared Available Units = 5.
Thread T0 requests 3 units, while Thread T1 requests 4 units. If both threads read the shared memory concurrently without synchronization, both observe 5 ≥ Request. Both subtract, resulting in 5 - 3 - 4 = -2 (Data corruption / Race condition hazard)!
